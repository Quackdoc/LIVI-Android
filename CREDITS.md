# Credits

LIVI-Android is based on [LIVI](https://github.com/f-io/LIVI) by Lasse Heitgres. It uses LIVI's user interface
(`livi-ui`), its Android Auto stack (`livi-aa`, `livi-aa-stack`), its settings and protocol crates and the rest of the
`livi-*` crates it builds against, and `src/core.rs` contains code taken from `livi-core`. LIVI's own credits, for the
projects it learned from, are in its [CREDITS.md](https://github.com/f-io/LIVI/blob/main/CREDITS.md).
